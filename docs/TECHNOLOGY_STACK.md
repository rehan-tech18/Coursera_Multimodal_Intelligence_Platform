# Technology Stack

## Project Name
Coursera Multimodal Intelligence Platform

## Technologies Used

| Technology | Purpose |
|---|---|
| Python | Main programming language |
| Streamlit | Frontend and user interface |
| Pandas | Data processing and analysis |
| OpenCV | Video frame processing |
| Faster-Whisper | Audio transcription |
| Google Gemini | AI-powered response generation |
| ChromaDB | Vector database |
| Sentence Transformers | Text embeddings |
| PyMuPDF | PDF document processing |
| python-pptx | PowerPoint file processing |
| SQLite | Educator review storage |
| Multimodal RAG | Retrieval of relevant educational evidence for AI-generated insights |

## How the Technologies Work Together

1. Python manages the application's main logic.
2. Streamlit provides the interface for educators.
3. Pandas processes educational data.
4. OpenCV and Faster-Whisper support video and audio processing.
5. Sentence Transformers generate text embeddings.
6. ChromaDB stores and retrieves vector information.
7. Google Gemini generates AI-powered insights.
8. SQLite stores educator reviews.

## Conclusion

These technologies work together to provide an AI-powered educational analytics and insight-generation platform.
