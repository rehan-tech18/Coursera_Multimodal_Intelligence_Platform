# User Guide

## Project Name
Coursera Multimodal Intelligence Platform

## Introduction
The Coursera Multimodal Intelligence Platform helps educators understand student learning performance, identify learning difficulties, and generate AI-powered teaching recommendations.

## How to Access the Application
1. Open the deployed Streamlit application using the live application link provided in the README file.
2. Wait for the application dashboard to load.

## Learning Analytics Dashboard
1. Open the Learning Analytics Dashboard.
2. Review student performance and quiz results.
3. Examine charts and key performance indicators.
4. Identify topics where students experience learning difficulties.

## Unified Educator Assistant
1. Open the Unified Educator Assistant page.
2. Select a topic or enter a question about student learning difficulties.
3. Submit the question.
4. Review the AI-generated insights and supporting educational evidence.

## Educator Review
1. Open the educator review section.
2. Review the generated insights.
3. Submit your feedback or review using the available controls.

## Conclusion
The platform helps educators analyse learning performance and make informed teaching decisions using AI-powered insights.
